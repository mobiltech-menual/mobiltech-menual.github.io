kakao API 발급절차 기술

## Description
카카오에서 제공하는 지도 및 로드뷰 등의 기능을 사용하기 위한 API 발급 매뉴얼


## Step1. 회원가입

1. [Kakao Developers](https://developers.kakao.com/) - API발급 사이트 접속


2. 상단 배너 - '로그인' 클릭

![Image](https://github.com/user-attachments/assets/2a9c759b-083f-4060-b222-c821431dadd5)


3. 로그인 페이지에서 ID/PW입력 하여 로그인

![Image](https://github.com/user-attachments/assets/80e061e4-f78d-4b60-8cc5-4736242dca0c)


4. 회원가입

![Image](https://github.com/user-attachments/assets/6b849a92-dd59-4462-8f19-b661996c4c4b)

## Step3. 애플리케이션 설정

1. 왼쪽 배너 - '플랫폼'클릭 -> 'Web플랫폼 등록'클릭

![Image](https://github.com/user-attachments/assets/7c9c2b02-47f1-4392-bf99-8bf9bef35ed3)

2. 로컬호스트 주소 입력

![Image](https://github.com/user-attachments/assets/34cdf2f2-5f14-4247-9a59-b5bd56db416d)

3. 왼쪽 배너 - '카카오맵'클릭 -> '활성화설정 상태 버튼(OFF)'클릭

![Image](https://github.com/user-attachments/assets/6da060ee-8cd7-4db2-9dec-42e228d300d0)
